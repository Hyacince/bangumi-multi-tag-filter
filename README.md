# Bangumi 收藏多标签筛选（Tampermonkey 油猴脚本）

官方收藏列表只能按**单个标签**查看（例如 `https://bgm.tv/anime/list/ashion/collect?tag=TV`），
这个脚本让你在收藏列表页**同时按多个标签筛选**：选好若干标签后一次性取出它们的全集，
按 **同时满足 (AND)** 或 **任一满足 (OR)** 合并，并按原站样式展示结果。

文件：`bangumi-multi-tag-filter.user.js`

---

## 功能

- **入口在标签区标题右侧**：打开自己的收藏列表页（`/anime/list/{用户名}/{状态}`）后，
  在 **“看过的标签” / “想看的标签” / “在看的标签”** 等标签区标题右边会出现「🏷 多标签筛选」按钮
  （页面里找不到标签区时兜底显示在右上角）；
- **双标签池**：
  - 「可选标签」按**标签数量从高到低**排序，**点击即添加**到已选；
  - 「已选标签」**点击即移除**（悬停变红提示）；
  - 支持搜索标签、手动输入标签（逗号分隔）、「重新读取」重新扫描页面标签；
- **两种关系**：同时满足 (AND，默认，取交集) / 任一满足 (OR，取并集)；
- **取全部条目再筛选**：对每个标签自动翻页抓取其完整条目列表，再合并去重，
  结果用**原站条目样式**渲染，并带客户端分页（每页 30 / 60 / 120 条）；
- **筛选结果持久化**：
  - 点进条目详情再**返回**列表页、或点顶部「按 评价／收藏时间／发售日／名称 排序」，
    筛选都会**自动恢复**（能复用缓存条目 HTML 时秒开；排序参数变化时按新排序重新抓取一次）；
  - 分页位置与每页条数一并记住；
  - 点 **「退出筛选」** 恢复原始列表，并清除持久化状态。

## 安装

1. 安装 Tampermonkey（Chrome/Edge / Firefox）；
2. 打开脚本地址安装：`https://raw.githubusercontent.com/Hyacince/bangumi-multi-tag-filter/main/bangumi-multi-tag-filter.user.js`
   （或新建脚本后粘贴本文件全部内容）；
3. 打开自己的收藏列表页，例如 `https://bgm.tv/anime/list/你的用户名/collect`，即可看到入口。

脚本自带 `@updateURL` / `@downloadURL`，通过上面地址安装后**会自动更新**。

---

## 使用

1. 点击标题右侧的 **「🏷 多标签筛选」** 打开面板；
2. 在「可选标签」里点击要用的标签（数量多的排前面）→ 标签进入「已选标签」；
   点错了就在「已选标签」里点一下移除；
3. 选择关系：想找**同时带多个标签**的条目用「同时满足」，想**合并几个标签的结果**用「任一满足」；
4. 点 **「应用筛选」**：状态栏会显示每个标签的抓取进度与条目数，完成后展示合并结果；
5. 结果区可用「‹ 上一页 / 下一页 ›」翻页；点 **「退出筛选」** 回到官方原始列表。

> 首次筛选某个标签时会逐页抓取（标签页翻页间隔 250ms、单标签上限 60 页），
> 之后同一会话内再调整筛选会直接复用已抓取的数据。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到入口 | 仅在本人的收藏列表页（`/anime/list/*`）生效；若页面标签区结构特殊，入口会兜底显示在右上角，可把该区域 HTML 反馈以适配 |
| 标签没有按数量排序 | 页面未提供标签数量时会提示「未读取到标签数量，暂按名称排序」；脚本已兼容括号数字、`num` 元素、外层容器、`title` 等多种标记，可将该区域 HTML 发来补充解析规则 |
| 封面显示过大／过小 | 脚本会实测原列表封面尺寸并显式套用到结果条目；若仍异常，说明页面结构特殊，可反馈结果条目的 HTML |
| 从条目页返回后筛选没了 | 筛选状态保存在 sessionStorage：**同一标签页**内返回会恢复；新开标签页、无痕窗口、清理浏览器数据后会丢失，需重新筛选一次 |
| 点了顶部排序后结果顺序没变 | 排序参数变化时会按新排序重新抓取，状态栏会显示「正在恢复筛选结果（按当前排序重新读取）…」，等待抓取完成即可 |
| 结果不全 | 单标签最多抓 60 页；若某标签条目特别多（>1800 条）会显示已抓到的部分，可反馈以便提高上限 |

## 技术说明

- 仅在 `bgm.tv / bangumi.tv / chii.in` 的 `/anime/list/*` 页面注入，`@grant none`、同源 `fetch`，**无需令牌**；
- 标签 URL 复用官方格式：`当前路径 + ?tag=<标签>&page=N`，并保留 `orderby` 等排序参数；
- 结果条目直接从抓回的标签页 HTML 中克隆，克隆时移除 `id` 以免与隐藏的原列表重复；
- 只读取页面数据，不修改任何收藏信息。
